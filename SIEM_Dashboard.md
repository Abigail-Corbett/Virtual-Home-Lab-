# Wazuh SIEM Dashboard

## Project Overview
The main objective is to create and connect a SIEM dashboard to the virtual home lab environment to log network traffic and attacks.  

## Tech Stack
* **Virtualization:** Oracle VirtualBox
* **Attacker OS:** Kali Linux
* **Victim OS:** Metasploitable 2
* **Networking:** Host-Only Adapter (Isolated environment for maximum safety)
* **SIEM Dashboard:** Wazuh OVA
